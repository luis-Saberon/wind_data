Anemometer is 81000 RM Young UVW Sonic Anemometer https://www.campbellsci.ca/81000

Documentation can be found at https://s.campbellsci.com/documents/ca/manuals/81000_man.pdf

File format for the anemometer data is Windspeed (m/s), Azimuth range(deg), Speed of Sound (m/s), Sonic Temp(C)
