Just looking at the values, I'm assuming that the values outputted are different from the default values shown in the document. 

The output for the raw anemometer file is time(HHMMSS), UVW Values(m/s), Sonic Temperature (C), and speed of sound(m/s)

  UVW values, where U values are aligned east-west (East-West is Positive), V is aligned north-south (North-South is Positive), and w is up-down (Updraft is Positive values). 


File format for the processed data is just the time displayed as a decimal format + the default format
UVW wind components represent a 3D wind velocity vector, where U is the zonal (east-west) speed, V is the meridional (north-south) speed, and W is the vertical speed
